이탈률 10.4% / 모수 6,244건 맥락에서 본 우선순위

✅ 순증 +802건 — 비즈니스는 성장 중 → 이탈 절감이 곧 가속도

신규 944명 유입으로 순증 +802건 달성. 이탈률 10.4%를 5%대로 줄이면 순증은 ~1,100건 수준. 지금은 획득보다 유지에 집중할 타이밍.

🔴 중복 구독 UX 버그 (~25건) → 즉시 수정 가능한 이탈

기타사유 83건 중 약 30%가 중복 결제·구독 실수. 구독 신청 완료 시 "이미 활성 구독이 있습니다" 확인 팝업 하나로 방지 가능. 코드 수정으로 ROI 최고.

🔴 품질 불만 1위 (23.7% · 137건) → 상품·배송 품질 개선

"꽃이 빨리 시들어요", "구성이 약해요" — 여름 및 3~4월 집중. 계절별 품종 전략과 포장 개선 필요. 전체 모수 6,244 대비 2.2% 이탈 원인.

🟡 직접 선택 선호 2위 (23.0% · 133건) → 큐레이션 UX 개선

품질 불만 + 직접 선택 선호 = 46.7%가 같은 맥락. 초기 취향 설문 + '원하는 꽃 1가지 픽' 옵션 도입. 초기 3회 내 취향 확인 플로우가 핵심 레버.

🟡 1~3회 이탈 최다 (208건 · 전체 32%) → 온보딩 Critical Zone

첫 배송 피드백 수집 & 2회차 전 취향 확인 플로우 필수. 모수 6,244 기준 3.3%가 초기 3회 내 이탈. 이 구간 10% 개선 시 ~20건 추가 유지.

🔵 3~4월 이탈 급증 (평균 대비 +75%) → 봄 시즌 원인 분석 필요

3월 108건·4월 102건 (월평균 ~58건). 봄 꽃 품질 저하 또는 가격 인상 체감 가능성. CS 로그 & 배송 품질 데이터 크로스 분석 권장.

⚪ 7회차+ 장기 구독자 이탈 201건 → Loyalty + 자동정지 복구

장기 구독자 '사유없음' 24건 — 조용히 떠나는 패턴. 자동정지 34건은 결제 수단 업데이트 유도로 회수 가능. 6개월+ 구독자 감사 혜택 도입 필요.
