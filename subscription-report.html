① 전년 동기간 신규 구독의 75%가 "배송비만 낸" 프로모 고객이었습니다

전년 동기(24.09~25.07) 신규 구독 1,119건 중 840건이 첫 회차에 5,000원 이하(배송비 4,400원)만 냈습니다. 이 중 47.7%가 단 1회만 받고 이탈했고, LTV 중앙값도 21,900원에 그칩니다. 이 때문에 전년도 이탈률, 신규 유입 수, LTV 숫자가 모두 왜곡되어 있습니다.

→ 전년과 올해를 직접 비교할 때는 반드시 이 프로모 효과를 제거하고 봐야 합니다.

② 정책 변경 후 외형 신규는 줄었지만, 진짜 유료 구독은 3.4배로 늘었습니다

전년 정상 결제 구독(프로모 제외)은 279건이었는데, 정책 변경 후(25.09~26.07)에는 962건으로 늘었습니다. 외형상 신규가 줄어 보이는 건 프로모가 없어졌기 때문이지, 실제 유료 구독 수요는 증가했습니다.

→ 숫자가 줄어 보여도 패닉할 필요 없음. 단, 1인당 LTV는 별개 문제입니다.

③ 3개월 기준 LTV 격차는 -6%로 좁혀졌지만, "6개월 벽"이 생겼습니다

구독 후 3개월만 잘라 비교하면 전년 정상결제 91,350원 vs 정책변경 후 85,525원으로 격차는 -6.4%에 불과합니다. 문제는 그 이후입니다. 정책변경 후 구독자는 6개월 LTV와 10개월 LTV가 95,600원으로 동일 — 6개월 이후 추가 결제가 사실상 없습니다. 전년 정상결제는 같은 구간에서 +21.8% 성장했습니다.

→ 초기 격차보다 6개월 시점의 성장 정체가 진짜 문제입니다. 6개월 차 리텐션 개입이 필요합니다.

④ 이탈 사유 1위 "품질 불만"(29%) + 2위 "직접 선택 선호"(22.7%) = 절반이 같은 맥락입니다

두 사유를 합치면 51.7%가 "내가 원하는 꽃을 못 받았다"는 뜻입니다. 기타 자유입력 사유 1위는 여전히 중복 구독 실수(~35건)로, UI 하나로 즉시 막을 수 있는 이탈입니다. 그리고 이탈 피크가 5~6월(141·138건, 월평균의 1.7배)로 이동 — 여름 초입 품질 불만(5~7월 quality 사유 급등)이 새 리스크입니다.

→ 취향 수집 온보딩 + 중복 구독 방지 팝업이 가장 빠른 이탈 감소 방법입니다.

정지·해지한 고객이 직접 선택하거나 입력한 사유를 분석합니다. 어디를 먼저 고쳐야 하는지 우선순위를 잡을 수 있습니다. ※ 사유는 복수 선택 가능 — 이탈 908건에서 1,039개 사유 수집 (25.09.23~26.07.20)

품질 불만(29%) + 직접 선택 선호(22.7%) = 51.7% — 결국 "원하는 꽃을 못 받았다"는 같은 맥락

몇 회차에 가장 많이 정지하는가

구독을 몇 번 받은 뒤 정지하는지 보여줍니다. 언제 집중 관리해야 하는지 알 수 있습니다

1~3회차에 425건(41%) 이탈 — 처음 3번이 구독 유지의 결정적 구간. 결제 전 이탈도 179건

품질 불만 직접 선택 선호 단순 변심 부재·수령 기타

"기타" 자유입력 사유 안에 뭐가 있는가 (~140건)

고객이 직접 입력한 기타 사유를 읽고 패턴별로 분류했습니다

기타의 25%가 "중복 구독 실수" — UI 하나로 즉시 막을 수 있는 이탈. "플랜·계정 전환"도 다수 (이탈 아닌 전환)

⚠️ 중복 결제·구독 실수~35건

"두번 신청됐어요" "이중구독이 됐습니다" — 구독 완료 시 중복 확인 팝업으로 즉시 해결 가능

🔄 플랜·계정 전환~20건

"플로픽으로 바꾸려고" "남편 계정으로 다시" — 이탈이 아닌 전환. 플랜 변경 플로우가 없어 정지·해지로 잡힘

🌸 계절·날씨~12건

"여름엔 빨리 시들어서" "가을부터 다시" — 계절 일시정지 기능 니즈, 5~7월 이탈 급증과 일치

💸 가격 부담~10건

"매달 금액이 부담돼요" "가격이 올라서" — 가격 인상 언급 다수, 가격 민감층 이탈

🔴 즉시 수정 — 중복 구독 방지 팝업 + 플랜 변경 플로우 (예상 감소: ~55건)

중복 구독(~35건)은 "이미 활성 구독이 있습니다" 팝업 하나로 막을 수 있습니다. 플랜·계정 전환(~20건)은 정지/해지 대신 "플랜 변경" 버튼을 제공하면 이탈 통계에서 사라지고 고객 경험도 좋아집니다.

🟡 온보딩 개선 — 취향 수집 + 첫 3회 집중 관리

품질 불만(29%) + 직접 선택 선호(22.7%)를 동시에 해결하는 방법은 "처음부터 취향을 물어보는 것"입니다. 가입 시 색상·꽃 종류·알러지 여부를 수집하고 1~3회 배송에 반영하면, 이 구간 이탈을 줄일 수 있습니다.

🟡 여름 시즌 대응 — 5~7월 이탈 급증은 "더위에 꽃이 시듦"

5월 141건·6월 138건으로 월평균(83건)의 1.7배, 품질 불만 사유도 5~7월에 급등(44·59·32건). 자유입력에도 "여름엔 빨리 시들어서"가 반복됩니다. 여름 전용 품종·배송 보냉 개선 또는 계절 일시정지 옵션(가을 자동 재개)이 필요합니다.

결론: 3개월 기준 격차는 -6.4%로 크지 않습니다. 진짜 문제는 "6개월 벽" — 정책변경 후 구독자는 6개월 이후 추가 결제가 사실상 없습니다.

🔴 3→4회 구간 개입이 가장 중요합니다

3번 받고 나서 4번째를 결정하는 시점. 이 타이밍에 "다음 배송 예고 + 취향 확인 메시지"를 보내는 것만으로 이탈을 줄일 수 있습니다. 3회 배송 완료 후 3~5일 이내 개입이 핵심입니다.
