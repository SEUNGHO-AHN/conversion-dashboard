단계별 이탈 개선폭 — 다음 시즌 개선 기대효과 포함
막대 높이 = 이탈률 개선폭 (%p) / 높을수록 더 많이 개선
최종 성과 — 결제 +34%
진입 +7.8%라는 소폭 증가로 결제완료 +396건(+34.0%) 달성. 퍼널 효율이 복리로 작용. 진입 1명당 결제 기여 0.043 → 0.054건(+26%)으로 향상.
UI 개선 — 간접 효과가 본체
add_to_cart 직접 구간 +0.2%p로 사실상 미미. 그러나 3단계(-2.9%p)·4단계(-6.7%p)에서 간접 효과 크게 발현. "원하는 옵션 정확히 담은 사람이 끝까지 완료"한 구조.
다음 타겟 — 장바구니 이탈 53%
3단계가 여전히 볼륨 손실 최대 구간. 이 구간 10%p 개선 시 결제완료 +250건 추가 기대. 배송비 노출 위치·쿠폰 UX·장바구니 재방문 리마인더가 핵심 레버.
4/29 이상치 — 내년 방어 필요
4/29 진입 2,443명(기간 최대)인데 전환율 2.74% 최저. 이 날 제거 시 전체 전환율 ~5.7%로 상승. 내년 동일 시점 유입 소스 모니터링 및 저품질 트래픽 차단 필요.
어버이날 레퍼런스화
5/5 결제 194건(25년 75건 대비 +159%). 진입도 2배. 넛지 타이밍·소재·상품 구성을 내년 플레이북으로 고정해야 함.

기아차 — 111M 신규 창출
b2b 채널에서 4종으로 111.4M 순증. 전체 시즌 매출(200.8M)의 55.5%를 차지. 베이직 꽃바구니(42.9M)·피움 센터피스(40.5M)가 양대 축.
피움 센터피스 — 실제 감소 확인
etc 제외 홈페이지 기준 주문 2,310 → 1,976건(-14.5%), 매출 44.8M → 41.0M(-8.5%). 기존 분석의 수량 증가는 etc 채널 대량 물량이 섞인 결과였음. 개인 고객 이탈 원인 파악 필요.
허그미 라인 두 상품 모두 성장
핑크레드 +63.6%, 작약 +31.0%. 홈페이지 채널에서 가장 안정적인 성장. 중가 대중 상품으로서 견고한 수요 확인. 다음 시즌 라인업 기준 상품.
프리미엄 꽃다발 단가 -16.9%
주문 +92.9% 성장했지만 단가 75,023 → 62,373원으로 하락. 볼륨은 커졌지만 수익성 확인 필요. 할인·프로모션 의존 성장 가능성.
채널 분리 기준 중요
etc 채널 포함 시 피움 센터피스 수량이 5,623개로 보였지만, homepage 기준 실제는 2,055개. 채널 구분 없이 합산하면 성과가 과대 계상됨. SQL 필터 필수.
